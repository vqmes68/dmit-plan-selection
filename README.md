## 三条线路才是分水岭

DMIT 的套餐命名看着乱，规律其实很简单：机房代号 + 平台代号 + 线路 + 档位，比如 `LAX.AN5.Pro.TINY` 就是洛杉矶、AN5 平台、Premium 线路、最小档。

| 线路 | 官方名 | 中国方向 | 价格水平 | 典型用途 |
| --- | --- | --- | --- | --- |
| Pro | Premium | 三网回程 CN2 GIA | 最高 | 面向国内访客的网站、业务 |
| EB | Eyeball | CMIN2 / AS9929 | 中等 | 国内访问 + 流量需求大 |
| T1 | Tier 1 | 国际线路，无国内优化 | 最低 | 海外业务、落地中转、下载备份 |

T1 便宜不是因为配置缩水，而是它压根没为回国流量做优化，流量给得反而最多。这就是为什么经常能看到"年付 $36.9 的 T1 比月付 $10.9 的 Pro 还便宜"这种反直觉的报价。

背景信息也交代一下：DMIT 成立于 2017 年，机房在洛杉矶、香港和东京，全系 KVM 虚拟化，AMD EPYC 处理器配 NVMe SSD，官方口径是不超售，支持支付宝、微信支付、PayPal 和信用卡，有中文客服。这些是它价格比同行贵一截的主要理由。

## 按需求挑，比按价格挑更快

把上面这些价格揉成几类真实场景，选择其实不难：

- **只想用最少的钱拿到一个海外节点**：洛杉矶或香港的 T1.WEE，$36.9/年，折下来月付 3 美元出头。做落地、监控、备份、下载都合适，唯一别指望的是国内访问速度。
- **预算敏感、要面向国内用户**：LAX.AS3.Pro.TINY，$10.90/月，或者 AN5 平台的 $12.98/月。1 核 2G 配 1TB 流量，个人站和小项目够用。
- **移动或联通用户、流量吃得多**：选 LAX EB，同价位流量比 Pro 多一倍。EB.MICRO 是 160GB 硬盘配 14TB 月流量，$87.90/月。
- **延迟优先、做直播或低延迟中转**：香港 Pro，月付 $39.9 起步。贵是真的贵，但香港 30–50ms 和洛杉矶 140–160ms 的感受差得很明显。
- **正式业务、要稳一点**：从 STARTER 档往上走，或直接上 EB.MEDIUM 这类 30TB 流量的型号。低配档位更适合测试。
- **纯海外业务、大流量场景**：T1.MEDIUM 及以上的大网口配置，$49.9/月换 32TB 月流量，在优化线路里找不到这个量级。

## 下单前确认这几件事

买之前花两分钟核对，比事后开票快。

库存和价格只是参考。DMIT 的分档和报价调整过好几轮，AN4、AS3、AN5 几代平台交替上架，所以上面所有数字都以下单页显示为准，这篇整理的是结构和你该怎么选，不是一份永久报价单。

新平台要留个心眼。官方自己提示过，AS3 平台仍在持续建设和优化阶段，磁盘性能和 SLA 可能低于成熟平台。正式业务尽量先跑测试再迁数据，顺手做异地备份。

换 IP 政策因套餐而异。部分套餐提供免费更换 IP 的服务，条件一般和激活时长、剩余有效期挂钩，不是所有档位都能享受。这条规则对"IP 被墙"的场景影响很大，下单前值得看一眼具体条款。

退款窗口不长。官方有有限退款政策，条件涉及购买天数和已用流量，具体数字以服务条款为准。不确定的话，先买最低配试一个月，比一次性年付高配更划算。

付款方式对国内用户友好，支付宝和微信支付都能走，不用为付一笔款去折腾外币卡。

最后一句实话：如果你只是想要个便宜的海外 VPS 学 Linux 或者跑点小脚本，T1 的 $36.9/年就够，没必要为 CN2 GIA 多付十倍价钱。真正需要 Pro 或 EB 的，是那些访问速度和稳定性会直接变成业务成本的人。
